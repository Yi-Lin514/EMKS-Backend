版本：v3.0
生效日期：2024 年 7 月 1 日
文件編號：DE-QA-001
制定單位：品管部

一、公司簡介與品質方針

Demo 電子股份有限公司成立於 2005 年，專業生產工業用電源供應器並提供 PCB 組裝代工服務，已通過 ISO 9001 與 ISO 14001 認證。本公司品質方針為：

「品質第一、交期承諾、持續改善、客戶滿意」

展開說明如下：
1. 品質第一：所有業務決策以產品品質為優先考量，不因成本或交期妥協於不符合規格之產品。
2. 交期承諾：以客戶承諾日期為最高使命，建立預警機制確保交期達成率 95% 以上。
3. 持續改善：透過 PDCA 循環與 KPI 追蹤，每季度檢討並提出改善方案。
4. 客戶滿意：每年進行客戶滿意度調查，目標分數 4.0/5.0 以上。

二、組織與職掌

品質管理系統由總經理授權品管部經理擔任管理代表（Management Representative, MR），負責品質系統之建立、導入與維持。

各部門在品質系統中之角色：
1. 業務部：客戶需求確認、合約審查、客訴窗口。
2. 研發部：產品設計、設計驗證、變更管制。
3. 採購部：供應商評鑑、進料品質協調。
4. 製造部：製程執行、生產紀錄、異常反應。
5. 品管部：IQC/IPQC/OQC 三階段檢驗、內部稽核、不合格品管制。
6. 資訊部：ERP 系統、MES 系統、電子化品質紀錄維護。
7. 人資部：品質相關教育訓練規劃與紀錄。

三、品質管理流程總覽

1. IQC（進料檢驗）：原物料與零件進廠後由品管部依抽樣計畫（MIL-STD-105E Level II）檢驗，不合格批退回供應商並開立 SCAR。
2. IPQC（製程檢驗）：生產過程中每 2 小時抽檢一次，涵蓋外觀、焊接品質、電性測試。異常立即停線並通知工程師。
3. OQC（出貨檢驗）：成品入庫前依 AQL 0.65 抽檢，包含功能測試、包裝檢驗、標籤核對。
4. 可靠性測試：部分產品依客戶要求進行高溫高濕、振動、ESD 測試。

四、關鍵 KPI

1. 進料不良率（IQC Reject Rate）：年度目標 < 2%。
2. 製程不良率（IPQC Defect Rate）：年度目標 < 1.5%。
3. 出貨不良率（OQC Reject Rate）：年度目標 < 0.3%。
4. 客訴件數：年度目標 < 24 件（月平均 2 件以下）。
5. 客戶滿意度：年度目標 ≥ 4.0（5 分制）。
6. 準時交貨率（OTD）：年度目標 ≥ 95%。

KPI 每月由品管部彙整，於品質月會（每月第一個週一上午 10:00）報告。

五、內部稽核

1. 頻率：每半年一次，每年共兩次。
2. 稽核員：由通過 ISO 9001 內稽員訓練之跨部門同仁輪派擔任，避免稽核自己所屬部門。
3. 稽核範圍：ISO 9001 所有條款 + 客戶特殊要求。
4. 稽核結果：開立不符合事項（NCR）並追蹤結案，作為管理審查輸入。

六、不合格品處理

1. 識別：不合格品須以紅色標籤明確標示，隔離於不合格品區。
2. 評審：由品管部召集製造、研發、業務進行處置評審。
3. 處置方式：重工（Rework）、報廢（Scrap）、特採（Use as is，需客戶書面同意）、退供應商。
4. 紀錄：所有不合格品處置紀錄於 ERP 系統，保存 7 年。

七、持續改善機制

1. 矯正與預防措施（CAPA）：針對已發生或潛在之不符合事項開立 CAPA 單，追蹤直至驗證有效為止。
2. QCC（品管圈）活動：每年舉辦至少 2 個 QCC 小組，由跨部門員工針對特定主題進行改善，年底發表並評選優秀案例。
3. 改善提案制度：員工可隨時提出改善建議，採納者依效益給予 NTD 500 至 NTD 10,000 獎金。

八、文件與紀錄管制

1. 文件編號規則：DE-[部門代碼]-[流水號]，例如 DE-QA-001 為品管部第 1 號文件。
2. 文件版本：採三位流水號 v1.0 起始，小修訂升 0.1，大修訂升 1.0。
3. 文件生效：經管理代表核准後於品質系統公告，舊版本立即失效並註記。
4. 紀錄保存期：品質紀錄 7 年、人員訓練紀錄在職期間 + 離職後 3 年、客訴紀錄 7 年。
