# Demo 文件生成提示詞

此目錄放 8 份 demo 用的公司文件，供 EMKS seed 流程讀取並向量化。

**做法**：把下方「情境設定」跟「每份文件的提示詞」貼到 ChatGPT，產生內容後存成 `.txt` 檔放進此目錄。

**檔案命名（照 seed_demo.py 的 DOCUMENTS 清單）**：
```
01_員工手冊.txt
02_資安規範.txt
03_報銷流程.txt
04_出差規範.txt
05_新人Onboarding.txt
06_客訴處理流程.txt
07_ISO品管手冊.txt
08_生產SOP.txt
```

**格式要求**：
- 純文字 `.txt`，UTF-8 編碼
- 不要用 Markdown 語法（`#`、`*`、`-` 這些），用純文字條列（例如 `一、`、`1.`、`(1)`）
- 每份 800-1500 字
- 繁體中文、台灣企業用語

---

## 情境設定（貼給 ChatGPT 當 system prompt）

```
你是一家台灣中型電子製造業公司的人資暨管理部專員，負責撰寫公司內部文件。

公司背景（所有文件要保持一致）：
- 公司名：Demo 電子股份有限公司（簡稱 Demo 電子）
- 成立時間：2005 年
- 員工數：約 350 人
- 地點：新北市土城區（總部兼工廠）
- 產品：工業用電源供應器、PCB 組裝代工
- 組織：管理部、資訊部、製造部、品管部（加上未獨立成文件的財務部、人資部、業務部）
- 主要客戶：工業自動化廠商、醫療設備廠商（B2B）
- 通過認證：ISO 9001、ISO 14001

撰寫原則：
1. 內容要具體、可執行，不要只有抽象原則
2. 使用台灣職場常見用語（例如「簽核」不是「審批」、「主管」不是「領導」）
3. 提到金額用新台幣（NTD），電話格式用 02-xxxx-xxxx
4. 不要用 Markdown 語法（#、*、-），用純文字條列（一、二、三 或 1. 2. 3.）
5. 每份文件 800-1500 字
6. 文件頂端註明「Demo 電子股份有限公司」+ 文件名稱 + 版本（例如 v1.0）+ 生效日期（自訂 2024 年的日期）
```

```

具體情境範例至少 2 個：例如「某員工收到假裝是客戶的附件檔要求開啟」該怎麼做。
```

## 提示詞 5 — 新人 Onboarding

```
請撰寫「Demo 電子股份有限公司 新人到職引導手冊」。

情境：新員工第一天到第一個月需完成的事項清單。

   - 報到時間（早上 9:00 到人資部）
   - 需攜帶文件（身分證、最高學歷證明、銀行存摺影本、健保轉出單）
   - 領取物品（員工識別證、筆電、門禁卡、制服 2 套）

   - 參加新人訓練（公司簡介、產品介紹、資安教育各 2 小時）
   - 環境導覽（工廠動線、茶水間、逃生路線）
   - 認識部門同事與 mentor
三、第一個月
   - 完成 ISO 9001 線上課程（品管部提供）
   - 與直屬主管進行一次 1-on-1
   - 提交第一份 30 日心得報告
四、設備申請流程
   - 筆電由資訊部預配，分機申請需填表
   - ERP 帳號第 3 天開通
   - 公司 Email 格式：姓名拼音@demo-electronics.com.tw
五、Mentor 制度（前 3 個月由同部門資深同事擔任，每週 30 分鐘聊聊）

聯絡人：人資部林小姐，分機 205。
```

## 提示詞 6 — 客訴處理流程

```
請撰寫「Demo 電子股份有限公司 客訴處理作業辦法」。

涵蓋內容：
一、目的與適用範圍
二、客訴分類
   - 產品品質（不良率異常、規格不符）
   - 交期延誤
   - 服務態度
   - 其他
三、處理時效
   - 接收後 24 小時內回覆客戶已受理
   - 72 小時內提出初步分析
   - 7 個工作日內提出正式回覆與改善方案
四、跨部門分工
   - 業務部：對外窗口、客戶溝通
   - 品管部：品質類客訴調查、8D 報告
   - 製造部：製程問題回溯
   - 資訊部：系統類客訴協助
五、8D 報告流程（D1 問題描述 → D8 結案）簡要說明
六、升級機制（3 次以上同類客訴、或單次金額損失 > NTD 50 萬即升級至總經理層）
七、年度客訴統計與檢討（每年 1 月由品管部彙整前一年客訴）

客訴受理窗口：業務部 service@demo-electronics.com.tw，專線 02-2260-xxxx 分機 0。
```

## 提示詞 7 — ISO 品管手冊

```
請撰寫「Demo 電子股份有限公司 ISO 9001:2015 品質管理系統手冊」摘要版。

涵蓋章節：
一、公司簡介與品質政策（品質方針一句話 + 展開說明）
二、組織與職掌（品管部與其他部門在品質系統中的角色）
三、品質管理流程總覽（進料檢驗 IQC → 製程檢驗 IPQC → 出貨檢驗 OQC）
四、關鍵 KPI
   - 進料不良率 < 2%
   - 製程不良率 < 1.5%
   - 出貨不良率 < 0.3%
   - 客訴件數年度目標
五、內部稽核（每半年一次，品管部主導，跨部門輪派稽核員）
六、不合格品處理（隔離 → 評審 → 處置：重工/報廢/特採）
七、持續改善機制（CAPA、QCC 小組活動）
八、文件與紀錄管制（7 年保存期、ISO 文件編號規則 DE-QA-001 之類）

強調這是摘要，完整 SOP 見各子文件。
```

## 提示詞 8 — 生產 SOP

```
請撰寫「Demo 電子股份有限公司 PCB 組裝生產作業標準程序（生產 SOP）」。

情境：針對公司主力產品「工業用電源供應器」的 PCB 組裝生產線操作規範。

涵蓋：
一、目的與適用範圍（適用 SMT 打件至組裝出貨全流程）
二、生產前準備
   - 備料核對（BOM 對照表、料號、數量、批號）
   - 設備點檢（SMT 機台、回焊爐溫度曲線確認）
   - 靜電防護（穿靜電衣、靜電環、環境濕度 40-60%）
三、作業流程步驟（用步驟編號，每步驟包含：作業內容、檢查重點、異常處理）
   1. 上錫膏印刷
   2. SMT 貼片
   3. 回焊
   4. AOI 自動光學檢測
   5. 插件（DIP）與波峰焊
   6. 功能測試
   7. 外觀檢驗
   8. 包裝與入庫
四、異常處理（作業中發現不良品 → 紅貼標籤 → 隔離區 → 品管判定）
五、交接班規定（每班次留下 3 項內容：今日產量、異常紀錄、待處理事項）
六、生產紀錄保存（電子檔 ERP 系統、紙本 QA 表單保存 5 年）

強調所有作業員上線前須完成 8 小時訓練與考核，認證通過才可獨立作業。
```
